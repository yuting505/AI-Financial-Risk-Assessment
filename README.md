# AI-Financial-Risk-Assessment
大三專題與資管 AI 自主學習第 1-2 週
本專案為資管系大三專題與研究所新生 AI 自主學習考核第 1-2 週之學習成果報告。
## 📝 本階段成果 (第 1-2 週考核)
- **分析目標**：台灣積體電路製造股份有限公司 (2330) - 民國 115 年第一季財務報告。
- **實作重點**：
  1. 使用 ChatGPT 搭配角色設定 Prompt（金融風險稽核分析師）進行最小可行原型 (PoC) 驗證。
  2. 測試 10 題涵蓋數據檢索、跨期比較、風險判讀與防幻覺陷阱題。
  3. 完成 AI 記憶覆蓋與跨頁表格讀取失誤之錯誤案例分析與改善反思。
